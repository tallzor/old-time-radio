# 声音时间机器｜页面原型与交互说明

版本：v0.1｜日期：2026-10-11｜依据：《规格说明.md》及《01-MVP开发计划.md》的建议基线。

本文是文字线框与交互规格，可用于设计和前端实施；并非已完成的视觉稿。范围调整仍待产品评审。

## 1. 导航与全局约定

主入口固定为“今日电台”“年代声音”“我的”，不把播放器当作第四个导航入口。播放详情由首页节目卡、收藏列表或分享链接进入。

| 页面 | 路由 | 进入方式 | 返回行为 |
|---|---|---|---|
| 今日电台 | `/` | 默认首页、底部导航 | 浏览器正常返回，不拦截退出 |
| 年代声音 | `/eras` | 底部导航 | 保留当前节目与播放状态 |
| 播放详情 | `/programs/:id` | 节目卡、收藏、分享深链 | 有站内来源则返回，否则回首页 |
| 我的 | `/me` | 底部导航 | 不停止播放 |
| 喜欢的声音 | `/me/likes` | 我的 | 回我的 |
| 收听偏好 | `/me/preferences` | 我的 | 保存后回原页 |
| 隐私说明 | `/privacy` | 我的／首次提示 | 返回来源页 |

全站共用一个播放器。首页与详情完整展示播放控制，其余页面底部显示当前节目名称和大号播放／暂停键；底部固定区不能盖住页面操作。直接打开某个分享节目详情只加载节目，不默认开始发声，也不替换已经播放的另一个节目；点击该详情的“开始收听”才切换。

播放器中的“播放”针对全局当前节目；分享详情若是不同节目，按钮写“收听这个节目”，同时保留全局正在播放信息，避免误认。

## 2. 首次使用与回访

### 2.1 首次打开

1. 首页立即显示收音机、推荐节目和“开始收听”，不先弹登录、偏好问卷。
2. 推荐默认范围为全部已开放年代和全部类型，从审核后的首播池选取。运营必须指定首播池；不得把待审核或空音频放入首播。
3. 次要提示“想听哪个年代？可以换一换”，不要求先做选择。
4. 底部简短提示保存偏好与使用数据的方式，并可查看隐私说明；具体同意机制随上线方案确认，非必要分析可关闭且不阻断收听。
5. 点击开始，按钮进入“正在准备声音”；真实开始后显示“暂停收听”。失败保持可重试按钮，不伪装播放中。

### 2.2 再次打开

恢复偏好并展示上次节目；本期重新打开从头开始，不实现跨会话断点续播。上次节目下架则加载同偏好候选，并提示“上次的节目暂时不能听，给您换了一段”。仍需点击开始。

同一页面会话内暂停后恢复，从当前时间继续。普通切页与返回保持进度。退出账号后清空账号相关前端状态，创建新游客身份，不把上一账号的收藏显示给新游客。

## 3. 今日电台文字线框

从上到下布局：产品名及一句说明 → 老式收音机主体 → 年代标签／内容类型 → 当前节目名称 → 大号播放／暂停按钮 → “换个节目” → “今日电台／年代声音／我的”导航。

收音机外观使用温暖底色、清晰刻度与旋钮造型；所有交互有文字标签。旋钮不要求精细拖动，年代选择用大按钮即可完成。

| 元素 | 行为 | 状态／说明 |
|---|---|---|
| 当前节目卡 | 进入详情 | 显示审核后的年代、标题、类型、分钟时长 |
| 开始／暂停 | 控制全局音频 | 加载、播放、暂停、重试状态明确；不得只换图标 |
| 换个节目 | 请求当前范围内下一条 | 连续点击只接受最后一次选择；待响应短暂禁用 |
| 年代与类型摘要 | 进入年代声音 | 默认“年代都可以 · 类型都可以” |
| 无候选 | 显示“这里还没有节目，换个年代试试” | 提供“选择年代”，不加载别的年代冒充匹配 |

今日电台使用已保存的偏好生成队列；年代声音中的临时选择只影响当前收听，不自动覆盖长期偏好。希望永久改变时去“我的→收听偏好”。

## 4. 年代声音文字线框

从上到下：标题“想听哪个年代？” → 年代按钮组 → 类型按钮组 → 匹配节目简要信息 → “就听这个” → 迷你播放器与导航。

年代单选：都可以、70年代、80年代、90年代、00年代。只显示至少有一条已上架内容的年代；今天不出现。类型单选：都可以、新闻、评书、小说、戏曲。根据已选年代展示可用类型；无内容类型可置灰并写“暂时没有”，不要让用户点完才发现空列表。

点击年代只更新选择与候选预览，不立即打断当前收听；点击“就听这个”应用组合、换台并尝试播放。选中的类型在新年代不存在时，明确切回“都可以”，显示简短提示“这个年代先听各类节目”。用户确认前仍可改选。

换台时旋钮动画建议约 300 毫秒；电流音默认关闭，可在偏好页打开。打开时使用短、低音量的已审核音效，不能覆盖节目开头或阻塞播放；不具备播放条件时直接省略。减少动态效果设置启用时不做旋转动画。

无库存变化时展示“这个年代暂时没有节目了”，保留旧节目的可见状态；正在播放的节目如也已下架，由播放器规则停止并说明，不能继续显示可播承诺。

## 5. 播放详情文字线框

从上到下：返回 → 年代与内容类型 → 节目名称 → 来源／重制标识 → 播放进度文字 → 大号播放／暂停 → 换个节目 → 喜欢／分享给家人 → 可忽略的反馈条。

| 控件 | 规格 |
|---|---|
| 标题 | 可换行，不截断关键信息；作品节选需明确 |
| 年份 | 有证据才显示“1985年”等具体年份；只有年代时显示“80年代” |
| 来源 | 原声、现代演绎、AI 重制分别标注；“历史事件播稿 · AI重制”不能称为当年录音 |
| 进度 | 显示“已听 03:20／共 12:00”；本期不加精细拖动条 |
| 喜欢 | “喜欢这个声音”↔“已喜欢”；再次点击取消；失败恢复原状态 |
| 换个节目 | 保持当前临时范围；新节目标题、年代与音频原子切换 |
| 分享 | 分享当前详情对应节目，不误分享另一个正在播放的节目 |

结束后自动请求下一条；受播放限制时显示“下一段准备好了，点一下继续”。不让反馈弹层挡住接播。如果候选只有当前一条，播放结束后停下，显示“这里暂时只有这段，重听一次／换个年代”。

### 5.1 反馈规则

同一 session 最多展示一次；同一身份间隔至少 24 小时。已有效收听 30 秒的节目结束时，或同一节目累计有效收听达 5 分钟时可触发。触发后在播放控制下方出现“喜欢这个声音吗？”以及“喜欢／一般／稍后”。不盖住控件、不要求回答、不停止音频。

反馈出现时固定绑定当时的 program_id 与 playback_id；后续自动换到新节目也不改变反馈对象。响应或忽略后收起。无可靠曝光记录时不计算反馈曝光率。

## 6. 我的、收藏与偏好

游客默认文案：“我的收音机”“收听偏好和喜欢的声音会保存在这个浏览器中；清除浏览器数据后可能找不回。”服务端可以存匿名数据，但不承诺同一老人换手机仍可恢复。

入口依次为：喜欢的声音、收听偏好、分享收音机、隐私说明、清除我的数据。清除动作需明确说明影响并二次确认，不误触执行。

P1 微信具备时再展示“登录后可在不同设备保存偏好与喜欢”，否则不展示不可用登录按钮。非微信环境保留游客收听，并提示需在微信中进行该登录方式，不反复跳转。

登录后显示“已登录”，不强制获取头像、昵称或手机号；我的增加“退出登录”。退出清理当前凭证并建立新游客身份，保留服务端账号数据。清除我的数据与退出是不同动作，说明必须区分。

收藏列表按收藏时间倒序，显示标题、年代、类型、播放与取消喜欢。空态：“还没有喜欢的声音，听到喜欢的点一下爱心。”下架内容显示“暂时无法收听”，允许取消收藏；不泄露草稿内容。

偏好页：年代单选、类型单选、换台音效开关、非必要分析开关、保存。多选后续再做。保存仅影响之后的今日电台队列，不突然换掉正在播放的内容。某偏好因下架无内容时保留原偏好记录，首页提示用户选择其他范围。

## 7. 分享与链接落地

- 微信内基础版：展示“点右上角，把这段声音分享给家人”，可以关闭；卡片接入为 P1。
- 支持系统分享时可调系统分享；失败／取消不报错打断播放，保留复制链接。
- 复制不可用时显示可选择的链接及操作说明。
- 节目链接 `/programs/:id?src=share`；产品链接 `/?src=share`。不携带用户 ID、授权 code 或会话 token。
- 接收者直接进入所分享节目，点击即听，不被偏好引导或登录遮挡。
- 链接过期／节目下架：显示“这段声音暂时不能听了”，提供“听听其他节目”。
- 只记录分享按钮点击、复制结果与带来源参数的落地打开；不把 SDK 配置成功当成实际发送成功。

## 8. 异常状态与用户文案

| 情况 | 展示与恢复 | 不允许的行为 |
|---|---|---|
| 初始化失败 | “暂时没连上，点这里再试一次” | 白屏、无限加载 |
| 浏览器拒绝播放 | “点一下开始收听” | 每秒重试或提示用户修改系统设置 |
| 10 秒未开始 | “声音还没准备好，重试／换个节目” | 按钮仍显示暂停 |
| 播放中断网 | 显示“网络有点慢”，停计时；可重试 | 将缓冲时间计为收听 |
| 来电／系统中断 | 以实际音频状态更新按钮；返回可恢复 | 未经用户操作突然提高音量 |
| 喜欢保存失败 | “没保存上，再点一次试试”并回滚 | 假装已保存 |
| 没有下一条 | “这里暂时只有这段” | 悄悄跳到别的年代 |
| 账号授权取消 | 返回我的并保留游客功能 | 循环拉起授权 |
| 音频已下架 | 停止并提示，给替代入口 | 继续从缓存队列选择它 |

## 9. 适老设计与验收

以下为本项目设计目标，不是声称已通过某种认证：正文建议 20–22 CSS px，标题 26–32 px；主要按钮至少 64 px 高，次要点击区域至少 48×48 px；字号可随系统放大。普通文字对比度目标 ≥4.5:1，选中状态同时用文字、形状和颜色说明。

不用仅图标按钮、不用仅滑动／长按触发功能，不要求精细拖动旋钮。按钮有焦点和可访问名称；旋钮装饰不抢焦点。320 px 宽屏和文字放大 200% 时不横向溢出，核心播放按钮仍可到达。动效不能闪烁，播放错误不靠颜色或声音单独表达。

设计交付清单：每页默认／加载／空／错误状态、播放详情全部状态、字体与间距标注、首播及分享落地路径、按钮文案、素材与字体可用依据。至少 5 位目标年龄用户试用时观察“是否知道点哪里、能否返回、能否暂停”，记录实际困难而非只询问“会不会用”。

## 10. 核心验收场景

1. 新用户不选择偏好、不登录，能从首页一次点击发起播放。
2. 年代切换只预览，确认后才换音频；新的标题与声音对应。
3. 首页→详情→我的→返回，节目和时间不重置、不叠加声音。
4. 快速连点换台，最终只有最后一次选择生效。
5. 游客喜欢后刷新能找到，取消后列表移除；失败能理解和重试。
6. 分享打开精确节目，未点击时不冒然发声；下架链接有去路。
7. 结束接播、空库、单条库存、断网、授权失败均有可操作状态。
8. 反馈不挡播放；进入后台或关闭页面不出现强制拦截。
